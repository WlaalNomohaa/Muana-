## 🔥 Key Features
<details>
<summary><b>🛡️ Security & Anti-Link System (Riix si aad u aragto)</b></summary>
* **1st & 2nd Warning:** Fariinta waa la tirtirayaa + Warning ayaa loo dirayaa user-ka.
* **3rd Warning:** Automatically **30 Seconds Timeout** ah ayaa lagu dhufanayaa.
* **Over 3 Times:** Mute/Communication Disabled + Waxaa loo dirayaa fariin ah admin ayaa xallin doona oo ay la socoto **Unmute Button** gaar u ah Admin-ka!
</details>
<details>
<summary><b>🔒 Server & Channel Moderation (Riix si aad u aragto)</b></summary>
* **`/lock` & `/unlock`:** Lock garee ama un-lock garee text channels-ka adoo adeegsanaya hal amar.
* **`/slowmode`:** Ka xakameee xawaaraha fariimaha channel-ka (Slowmode).
* **`/move`:** U rar user kasta Voice ama Text channel-ka aad doonto.
* **`/autorole`:** Role si otomaatig ah loo siiyo xubnaha cusub marka ay soo biiraan.
</details>
<details>
<summary><b>🎭 Fun & Utility Commands (Riix si aad u aragto)</b></summary>
* **`/slap`:** U dir dharbaaxo/slap GIF ah xubin kale oo server-ka ah.
* **`/help`:** Search system caawinaad ah (Autocomplete) oo leh qeybta *Another Problem* oo toos ugu xiriirinaysa Profile-ka Admin-ka.
* **`/writemsg`:** Ka codso bot-ka inuu fariin rasmi ah ka diro channel-ka.
</details>

## 📜 All Slash Commands

| :--- | :--- | :--- |
