# 🤖 Discord Moderation & Ticket Bot
Bot-kan waa bot loogu talagalay maaraynta server-ka Discord (Server Moderation), habaynta xubnaha cusub, amarrada amniga (Anti-link System), iyo habab caawinaad oo otomaatig ah.
---
## 🌟 Sifooyinka Bot-ka (Features)
* **📜 Search /Help System:** Menu caawinaad ah oo leh autocomplete iyo batoon loo adeegsado la xiriirka Admin-ka (`1483111151469465722`).
* **🚚 Advanced `/move` Command:** Amarka rarista oo kuu ogolaanaya inaad user kasta u rarto Voice Channel ama Text Channel kasta.
* **📝 Fast Messaging (`/writemsg`):** Ka codso bot-ka inuu fariin gaar ah ku diro channel-ka aad doorto.
* **⭐ Feedback System (`/feedback`):** Hab loo dhiibo fikradaha iyo qiimaynta xiddigaha (1 ilaa 10 stars).
* **🔒 Advanced Anti-Link Protection:**
  * **1 - 2 Jeer:** Tirtirid fariinta + Digniin (Warning).
  * **3-aad:** Tirtirid + **30 Seconds Timeout**.
  * **3 Jeer ka badan:** Fariin xiraad (Mute) + Fariin la yiraahdo Admin ayaa wax ka qaban doona oo uu la socdo **Admin Unmute/Fix Button**.
* **🎭 Auto-Role & Role Management:** Sii ama ka qaad roles-ka adoo adeegsanaya `/add-role`, `/remove-role`, iyo `/autorole`.
* **👀 Activity Status:** Bot-ku wuxuu si otomaatig ah u muujinayaa `Watching Maamulka Server-ka`.
---
## 📜 Amarrada Bot-ka (Slash Commands)

| Amarka | Qdescription | Permissions |
| :--- | :--- | :--- |
| `/help` | Tusa amarrada iyo xallinta dhibaatoyinka | *Dhamaan xubnaha* |
| `/move` | U rar user channel kasta oo aad rabto | `Move Members` |
| `/writemsg` | Ku amr bot-ka inuu diro fariin aad qortay | `Manage Messages` |
| `/feedback` | Dhiibo fikradaada iyo qiimayn xiddigo ah (1-10) | *Dhamaan xubnaha* |
| `/add-role` | Sii user role gaar ah | `Manage Roles` |
| `/remove-role` | Ka qaad user role uu leeyahay | `Manage Roles` |
| `/antilink` | Ka shid ama ka dami xakamaynta links-ka (`on`/`off`) | `Administrator` |
| `/autorole` | Habee role-ka otomaatiga ah ee xubnaha cusub | `Administrator` |
| `/setup` | Otomaatig u samee habaynta server-ka | `Administrator` |
| `/id` | So saar ID-ga User-ka ama Role-ka | *Dhamaan xubnaha* |
