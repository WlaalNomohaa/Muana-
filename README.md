✨ Features

«🚀 A powerful Discord bot for server management, moderation, and security.»

- 🆘 Help System
- 🚚 Move Members
- 📝 Send Messages
- ⭐ Feedback System
- 👤 Role Management
- 🔗 Advanced Anti-Link
- 🤖 Auto Role
- 🛡️ Admin Controls
- 🆔 ID System

---

🛡️ Anti-Link Protection

🔗 Link #1  → ⚠️ Warning
🔗 Link #2  → ⚠️ Warning
🔗 Link #3  → ⏳ 30 Seconds Timeout
🔗 Link #4+ → 🔇 1 Hour Timeout

---

📜 Commands

Command| Description
"/help"| 📚 Show help and bot information
"/move"| 🚚 Move a member
"/writemsg"| 📝 Send a message
"/feedback"| ⭐ Submit feedback
"/add-role"| ➕ Add a role
"/remove-role"| ➖ Remove a role
"/antilink"| 🔗 Enable/Disable Anti-Link
"/setup"| ⚙️ Setup the server
"/id"| 🆔 Get IDs
"/autorole"| 🤖 Setup Auto Role
